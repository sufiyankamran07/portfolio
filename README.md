# Futuristic Portfolio

A modern portfolio website for a Java full stack developer, built with React and Vite. The site showcases technical skills, project work, work experience, education, certifications, and contact information in a sleek cyber-inspired interface.

## Features
- Futuristic cyber-style layout
- Responsive design for desktop and mobile
- Project showcase cards
- Experience and education timeline
- Contact section with profile links
- Clean React + Vite architecture

## Tech Stack
- React
- Vite
- JavaScript
- CSS

## Run locally
```bash
npm install
npm run dev
```

## Build for production
```bash
npm run build
```
